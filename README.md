#### 三、 项目介绍

基于Python的医院管理系统分为前台用户模块及后台的医师、财务、医生、护士、管理员五大模块，具体功能如下：

（1）前台用户模块：首页、科室信息、医生信息、预约挂号、药品信息、个人中心
（2）后台医师模块：系统首页、个人中心、西药处方、药品信息、药品库存、取药信息、健康信息
（3）后台财务模块：系统首页、个人中心、医保核销、医院信息、发票信息、预约列表、财务控制
（4）后台医生模块：系统首页、个人中心、用户信息、科室信息、健康档案、检查预约、药品处方、医院信息、医保核销
（5）后台护士模块：系统首页、个人中心、科室信息、医院信息、诊疗执行、护理记录、病床信息、标本采集
（6）后台管理员模块：系统首页、个人中心、用户信息、医护人员、药品信息、财务信息、科室管理、出诊安排、挂号信息、就诊进度、设备信息、物资信息、物资采购入库、费用结算、医保核销、预算编制、预约挂号、成本控制、系统管理
#### 四、项目技术

是否前后端分离项目：是

后端： SpringBoot+Mybatis-Plus

前端：Vue + Vue Router + ELementUI + Axios

#### 五、 运行环境

开发语言：Java

项目架构：B/S架构

开发工具：IDEA，Eclipse,Myeclipse都可以。推荐IDEA

JDK版本：1.8

数据库: MySQL5.7

Tomcat环境：Tomcat 7.x,8.x,9.x版本均可

项目管理：Maven



#### 六、安装教程

1.使用Navicat或者其它工具，在mysql中创建对应名称的数据库，并导入数据库脚本里面的sql文件.

2.使用IDEA/Eclipse/MyEclipse导入项目，Ecipse/MyEclipse导入时

3.将项目中config.properties中的数据库配置改为自己的配置

4.启动项目
